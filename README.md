# Tonecraft

Tonecraft is a Figma plugin for making color and type systems without the
usual token-spreadsheet ritual.

Give it a brand color, choose a palette algorithm, and it makes useful color
ramps, variables, paint styles, and a small style guide in your Figma file.
It also builds type scales with real names like H1, Body, and Caption, because
"Step 4" is not exactly a personality.

Tonecraft is still a small project, but it is opinionated about one thing:
design tokens should help people design, not become a second job.
